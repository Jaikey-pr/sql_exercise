### 🛠 Как быстро заполнить этот шаблон (Pro Tips)

1. **Автогенерация Markdown-таблиц из результата запроса**  
   Не печатайте таблицы вручную! В большинстве современных IDE это делается в два клика:
   - **DBeaver**: Выполните запрос → Выделите все строки результата → Правая кнопка мыши → **Copy** → **Advanced Copy** → **Copy as Markdown**.
   - **DataGrip / IntelliJ IDEA**: Выполните запрос → Выделите результат → Правая кнопка мыши → **Copy** → **Copy as Markdown**.
   - **Azure Data Studio / SSMS**: Можно использовать расширение "Markdown Table Formatter" или скопировать в Excel, а затем конвертировать через онлайн-инструменты (например, *tablesgenerator.com*).

2. **Единый стиль SQL**  
   Чтобы репозиторий выглядел профессионально, отформатируйте все запросы в едином стиле. Например:
   - Ключевые слова (`SELECT`, `FROM`, `WHERE`, `JOIN`) с новой строки.
   - Выравнивание запятых и операторов.
   - Используйте комментарии `--` для объяснения нетривиальной логики (например, почему выбрано `LEFT JOIN` вместо `INNER JOIN`).

3. **Проверка перед коммитом**  
   В GitHub Markdown заголовки `##` автоматически становятся якорными ссылками. Убедитесь, что `Permalink: [N](#n)` точно соответствует нижнему регистру заголовка (например, `## 1` → `#1`). Это позволит ревьюеру мгновенно переходить к нужной задаче из оглавления файла.

4. **Корневой `README.md`**
