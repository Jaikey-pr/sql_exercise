# 🗄️ SQL Exercises (sql-ex.ru)

Этот репозиторий содержит мои решения обучающих задач с сайта [sql-ex.ru](https://sql-ex.ru/). 
Основная цель проекта — продемонстрировать навыки написания чистых, эффективных и читаемых SQL-запросов, а также понимание реляционных баз данных.

## 📚 О проекте

В данном репозитории представлены решения первых 20 задач обучающего этапа. Задачи охватывают две классические учебные базы данных:
1. **Компьютерная фирма** (`Product`, `PC`, `Laptop`, `Printer`)
2. **Корабли** (`Classes`, `Ships`, `Outcomes`)

Все решения оформлены в едином стиле: с условием задачи, отформатированным SQL-кодом, краткими комментариями по логике решения и таблицей ожидаемого результата.
